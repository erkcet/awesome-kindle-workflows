# Contribution Guidelines

Please ensure your pull request follows these guidelines:

- Search existing entries and open pull requests before suggesting an item.
- Add one logical suggestion or closely related group per pull request.
- Use the format `- [Name](https://example.com/) - Objective description.`
- Start each description with an uppercase character and end it with a period.
- Link to the canonical project page, official documentation, or upstream repository.
- Prefer actively maintained tools and resources with clear documentation.
- Explain the Kindle workflow the item enables and why it is among the best available options.
- Do not submit affiliate links, referral links, pirated-content sources, DRM-removal tools, or projects primarily intended to bypass access controls.
- Clearly identify projects that require a jailbroken device and verify model and firmware compatibility.
- Check spelling, grammar, and link validity.
- Run `npx awesome-lint` from the repository root before submitting.

Thank you for helping keep the list focused and useful.
