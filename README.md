# Awesome Kindle Workflows [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Practical workflows for organizing, converting, delivering, reading, and annotating legally obtained content on Amazon Kindle devices and apps.

This list emphasizes maintained tools, official documentation, privacy-conscious workflows, and format interoperability. It does not include DRM removal, pirated-content sources, or tools whose primary purpose is bypassing access controls.

## Start Here

- [Send to Kindle](https://www.amazon.com/sendtokindle) - Official web uploader for EPUB, PDF, office documents, images, and other supported files.
- [Send to Kindle by Email](https://www.amazon.com/sendtokindle/email) - Official personal-document delivery using an approved sender address.
- [Kindle for Web](https://read.amazon.com/) - Browser-based access to a synchronized Kindle library.
- [Kindle Reading Apps](https://www.amazon.com/kindleapps) - Official reading applications for phones, tablets, and computers.
- [calibre User Manual](https://manual.calibre-ebook.com/) - Documentation for managing, converting, cataloging, and transferring e-books.

## Library Management

- [calibre](https://github.com/kovidgoyal/calibre) - Cross-platform e-book library manager with conversion, metadata, device, and automation support.
- [calibre-web](https://github.com/janeczku/calibre-web) - Web interface for browsing, reading, and managing a calibre library.
- [calibre Content Server](https://manual.calibre-ebook.com/server.html) - Built-in web access and downloading for one or more calibre libraries.
- [calibre Command Line Interface](https://manual.calibre-ebook.com/generated/en/cli-index.html) - Automation commands for conversion, metadata, library operations, and server management.
- [calibre Plugins](https://plugins.calibre-ebook.com/) - Community-maintained extension index distributed through calibre.

## Delivery and Conversion

- [Kindle Comic Converter](https://github.com/ciromattia/kcc) - Converts comics and manga into e-reader-optimized files.
- [k2pdfopt](https://www.willus.com/k2pdfopt/) - Reflows and crops PDF and DjVu documents for small e-ink screens.
- [Pandoc](https://pandoc.org/) - Converts Markdown, HTML, DOCX, and other document formats into EPUB.
- [Sigil](https://github.com/Sigil-Ebook/Sigil) - Visual EPUB editor for repairing structure, metadata, navigation, and styling.
- [EPUBCheck](https://github.com/w3c/epubcheck) - Official EPUB conformance checker maintained by the W3C publishing community.
- [Kindle Previewer](https://kdp.amazon.com/en_US/help/topic/G202131170) - Official desktop previewer for checking how books render across Kindle devices and apps.
- [E-book Conversion](https://manual.calibre-ebook.com/conversion.html) - Guidance for converting and tuning documents for e-readers with calibre.
- [Send to Kindle for Chrome](https://www.amazon.com/sendtokindle/chrome) - Official browser extension for sending web pages to a Kindle library.
- [Push to Kindle](https://www.fivefilters.org/push-to-kindle/) - Browser and mobile tools for turning readable web pages into Kindle documents.

## Articles and Periodicals

- [calibre News Recipes](https://manual.calibre-ebook.com/news.html) - Scheduled feed and website conversion into e-book periodicals.
- [calibre Recipe API](https://manual.calibre-ebook.com/news_recipe.html) - Python API for custom news-fetching and content-cleaning recipes.
- [KindleEar](https://github.com/cdhigh/KindleEar) - Self-hostable service that aggregates feeds and delivers periodicals to e-readers.
- [EpubPress](https://epub.press/) - Browser extension that bundles selected web pages into a single EPUB.
- [wallabag-kindle-consumer](https://github.com/janLo/wallabag-kindle-consumer) - Sends tagged articles from a self-hosted wallabag account to Kindle.

## Highlights and Notes

- [Kindle Notebook](https://read.amazon.com/notebook) - Official web view for synchronized highlights and notes.
- [Readwise](https://readwise.io/) - Synchronizes Kindle highlights with review, note-taking, and knowledge-management workflows.
- [Kindle Highlights Exporter](https://xueboyang1985.github.io/kindle-exporter/) - Local browser tool that exports highlights to Markdown, CSV, or JSON.
- [noted](https://github.com/codito/noted) - Command-line workflow for exporting Kindle notes and highlights.
- [kindle2notion](https://github.com/paperboi/kindle2notion) - Imports Kindle clippings into a Notion database.
- [kindle-clippings-to-obsidian](https://github.com/dannberg/kindle-clippings-to-obsidian) - Converts the `My Clippings.txt` file into Obsidian-compatible Markdown notes.
- [KindleClippings](https://github.com/robertmartin8/KindleClippings) - Organizes local Kindle clippings into per-book text files.

## Kindle Scribe

- [Kindle Scribe](https://www.amazon.com/kindlescribe) - Official product page for Kindle models with pen and notebook support.
- [marginalia](https://github.com/VforVitorio/marginalia) - Converts exported Scribe notebook PDFs into reviewable Obsidian Markdown using local or cloud OCR.

## Alternative Reading and Device Tools

- [KOReader](https://github.com/koreader/koreader) - Document viewer optimized for e-ink devices with extensive format and typography controls.
- [KindleModding Wiki](https://kindlemodding.org/) - Community documentation for supported device customization and recovery procedures.
- [KindleTool](https://github.com/NiLuJe/KindleTool) - Low-level utility for inspecting and creating Kindle update packages.
- [KUAL](https://github.com/NiLuJe/KUAL) - Launcher for community extensions on supported jailbroken Kindle devices.
- [WordDumb](https://github.com/xxyzz/WordDumb) - Plugin that generates Word Wise and X-Ray data for supported book formats in calibre.

Device modification can void warranties or render a device unusable. Check the exact model and firmware compatibility before using customization tools.

## Free and Legal Books

- [Standard Ebooks](https://standardebooks.org/) - Carefully formatted public-domain e-books with modern typography and metadata.
- [Project Gutenberg](https://www.gutenberg.org/) - Large collection of public-domain e-books in multiple formats.
- [Open Library](https://openlibrary.org/) - Internet Archive catalog with lending and public-domain access where available.
- [Global Grey](https://www.globalgreyebooks.com/) - Public-domain e-books prepared in EPUB, PDF, and Kindle-friendly formats.
- [Baen Free Library](https://www.baen.com/allbooks/category/index/id/2012) - Publisher-authorized selection of free science-fiction and fantasy e-books.
